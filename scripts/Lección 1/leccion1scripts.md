# Lección 1: Introducción al desarrollo web

## Introducción

Hola a todos. 
Bienvenidos a la primera lección de nuestro curso de desarrollo web.

En esta lección conoceremos qué es un sitio web, cómo funciona y cuáles son las herramientas fundamentales para comenzar a crear páginas web: HTML y CSS. También hablaremos sobre la lógica y el pensamiento analítico, habilidades importantes para resolver problemas de programación.

## 1. ¿Qué es un sitio web?

Un sitio web es un conjunto de páginas conectadas entre sí y disponibles en internet. Podemos imaginarlo como un libro cuyas páginas contienen información, imágenes, videos o herramientas que los usuarios pueden consultar.

Los sitios web forman parte de nuestra vida cotidiana. Los utilizamos para buscar información, comunicarnos, estudiar, comprar productos, ver contenido multimedia y acceder a servicios en línea.

Para visitar un sitio web usamos un navegador, como Google Chrome. El navegador solicita la información del sitio y la muestra en la pantalla.

Esa información se almacena en un servidor, que es una computadora especializada y conectada a internet. Cuando escribimos la dirección de un sitio en el navegador, este solicita el contenido al servidor y lo presenta al usuario.

Los sitios web pueden tener distintos propósitos: informar, entretener, vender productos, ofrecer servicios o facilitar la comunicación. Por eso, son una herramienta fundamental para la educación, los negocios y el intercambio de información.

## 2. ¿Qué es el desarrollo web?

El desarrollo web es el proceso de crear páginas y aplicaciones web. Incluye la planificación, la creación y el mantenimiento de una solución que responda a una necesidad y sea fácil de usar.

Un desarrollador web convierte una idea en una experiencia digital funcional. Podemos compararlo con un arquitecto que diseña la estructura de un edificio: el desarrollador organiza y construye las partes que conforman un sitio o una aplicación.

## 3. HTML y CSS

Para crear páginas web necesitamos darle instrucciones al navegador. Dos herramientas fundamentales para comenzar son HTML y CSS.

HTML es un lenguaje de marcado que define la estructura y el contenido de una página. Indica dónde se encuentran los títulos, los textos, las imágenes, los botones y los enlaces. Podemos imaginarlo como el esqueleto de un cuerpo o los planos de una casa.

CSS es un lenguaje de estilos que controla la apariencia de la página. Con CSS elegimos colores, tipografías y tamaños, y organizamos los elementos en la pantalla. Si HTML es el esqueleto, CSS es la ropa y el diseño visual.

## 4. Lógica y pensamiento analítico

La programación consiste en dar instrucciones de forma ordenada. Por eso, la lógica y el pensamiento analítico son importantes para resolver problemas.

Antes de escribir código, debemos comprender el problema, identificar sus partes y pensar en los pasos necesarios para alcanzar un resultado. Un buen programador no solo memoriza comandos: también analiza situaciones y organiza soluciones.

## Conclusión

En esta lección aprendimos qué es un sitio web, cómo se comunica un navegador con un servidor y qué significa desarrollar para la web.

También conocimos HTML, que define la estructura y el contenido, y CSS, que se encarga de los estilos y la presentación. Finalmente, vimos por qué la lógica y el pensamiento analítico nos ayudan a resolver problemas de programación.
