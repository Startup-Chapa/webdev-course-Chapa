# Lección 6: Errores comunes y recomendaciones en el desarrollo web

**Duración:** 7 minutos

## Introducción

Hola a todos. Bienvenidos a la lección 6.

En esta última lección vamos a conocer algunos errores comunes que podemos cometer al crear una página web y cómo podemos corregirlos.

También veremos algunas recomendaciones que nos ayudarán a escribir código más ordenado y a mejorar nuestras páginas.

## 1. Errores comunes en HTML

Uno de los errores más frecuentes es olvidar cerrar las etiquetas.

Por ejemplo, cuando escribimos un párrafo, debemos utilizar la etiqueta de apertura `<p>` y su correspondiente etiqueta de cierre `</p>`.

Otro error es no definir correctamente la estructura del documento HTML.

Es recomendable utilizar las etiquetas `html`, `head` y `body` para organizar nuestra página.

También debemos indicar el idioma mediante el atributo `lang`.

## 2. Errores comunes en CSS

CSS nos permite cambiar la apariencia de nuestra página.

Sin embargo, debemos tener cuidado con los colores que utilizamos.

Por ejemplo, si configuramos el fondo de color blanco y el texto también de color blanco, el contenido será difícil de visualizar.

Para evitarlo, debemos utilizar colores que tengan suficiente contraste.

También es importante seleccionar tamaños de letra adecuados para facilitar la lectura.

## 3. Accesibilidad web

La accesibilidad busca que las páginas web puedan ser utilizadas por la mayor cantidad posible de personas.

Por ejemplo, cuando agregamos imágenes, debemos utilizar el atributo `alt` para describir su contenido cuando la imagen transmite información.

También debemos procurar que los enlaces tengan textos claros y que nuestra página pueda utilizarse mediante el teclado.

## 4. Buenas prácticas

Una recomendación importante es mantener nuestro código ordenado.

Podemos utilizar indentación para identificar fácilmente las etiquetas y sus elementos.

También es recomendable utilizar nombres descriptivos, revisar los enlaces y probar nuestra página en diferentes tamaños de pantalla.

Además, podemos consultar documentación confiable, como MDN Web Docs, cuando tengamos dudas sobre HTML o CSS.

## 5. Ejemplo práctico

Vamos a revisar una página que contiene algunos errores.

Primero observamos que el texto es blanco y el fondo también es blanco.

Para corregirlo, cambiamos el color del texto por uno oscuro.

Después identificamos un párrafo que no tiene su etiqueta de cierre.

Agregamos `</p>` para completar su estructura.

También observamos una imagen que no tiene descripción.

Agregamos el atributo `alt` con un texto que describa adecuadamente la imagen.

Finalmente, configuramos el idioma del documento, mejoramos el tamaño del título y agregamos la etiqueta `viewport` para adaptar la página a dispositivos móviles.

Al aplicar estas correcciones obtenemos una página más ordenada, legible y accesible.

## Conclusión

En esta lección aprendimos que los errores en HTML y CSS pueden afectar tanto la apariencia como el funcionamiento de una página web.

También vimos la importancia de la accesibilidad, la organización del código y las buenas prácticas.

Recuerda que aprender desarrollo web requiere practicar y corregir nuestros errores constantemente.

Con esto terminamos nuestro curso introductorio de desarrollo web.
