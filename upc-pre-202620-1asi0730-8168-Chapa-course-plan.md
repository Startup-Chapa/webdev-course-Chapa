# Fundamentos de Desarrollo Web
## Resumen del Curso
Este curso de 50 minutos introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **No
requiere descargas**, utiliza la herramienta en linea codepen.io.<br>
**Duración total**: 50 minutos<br>
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación<br>
**Prerrequisitos**: Ninguno<br>
**Herramientas necesarias**:<br> **Navegador web** (Chrome, Firefox, Safari, Edge)<br> **Conexion a internet**
<br>
**📂 Repositorio de código fuente**: [https://github.com/Startup-Chapa/design-web-course-Chapa](https://github.com/Startup-Chapa/design-web-course-Chapa)

## Secuencia de la lección
### Lección 1: Introducción al desarrollo web (5 minutos)
- *Descripción*: Conoce los usos principales de los sitios web y una introducción básica a su estructura.
- *Enlace*: [Ver la lección]()
- *Consejos clave*: Reconocer la estructura de un sitio web, sus usos y los componentes del desarrollo web.

### Lección 2: Estructura HTML Básica (7 minutos)
- **Descripción**: Aprende la estructura básica de una página utilizando HTML
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Utilizar etiquetas y atributos para crear tu primera página.
- **Práctica**: [Crea tu primera estructura HTML]() 👈 **¡No es necesario registrarse!**

### Lección 3: Elementos HTML comunes (6 minutos)
- **Descripción**: Conoce los elementos más usados en HTML
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Agregar referencias, encabezados, imágenes y enlaces.
- **Práctica**: [Aplica los elementos básicos]() 👈 **¡No es necesario registrarse!**

### Lección 4: Introducción a CSS (7 minutos)
- **Descripción**: Dale estilo a tu HTML con colores, fuentes y diseños.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Vincular CSS, usar selectores como `body { background-color: white; }`.
- **Práctica**: [Aplicar estilo con un clic]() 👈 **¡No es necesario registrarse!**

### Lección 5: Creación de página (tutorial simple) (7 minutos)
- **Descripción**: Pon a prueba el conocimiento aprendido de HTML y CSS para crear una página web simple.
- **Enlace**: [Ver la lección](https://youtu.be/dfddnsA7nMI?si=flhVmd5VweQTd5wU)
- **Consejos clave**: Crea una estructura con HTML y dale estilo con CSS.
- **Práctica**: [Pon a prueba lo aprendido](https://codepen.io/editor/mstardev/pen/01a1c77c-4ea8-722e-878e-e32f6e975b08) 👈 **¡No es necesario registrarse!**

### Lección 6: Errores comunes y recomendaciones en el desarrollo web (7 minutos)
- **Descripción**: Conoce errores comunes que los desarrolladores cometen en el desarrollo web y aprende consejos para principiantes.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Documentación, Accesibilidad, Buenas prácticas.
